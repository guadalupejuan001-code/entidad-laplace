Repositorio independiente de Laplace: investigación de estados, señales, evolución temporal y predicción experimental.

Migración desde `guadalupejuan001-code/LaPlaceDIG`, con módulos e integraciones relacionados de REVERSE-PC. Las predicciones financieras son experimentales; ninguna rama constituye una demostración de determinismo universal ni garantiza rendimientos.
