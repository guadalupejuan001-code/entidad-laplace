# Integración Laplace para REVERSE-PC

Esta carpeta es una copia de los archivos relacionados con Laplace en el proyecto Android REVERSE-PC, fijada al commit `311a9623382e8b5e0b87d00fd22c726ef332043a`.

Los recursos siguen las rutas originales para facilitar su reintegración: `laplace-android/` (preparación, contratos y pruebas) y `reverse-os-android/` (assets y tres clases Java anfitrionas).

**No constituye una aplicación Android independiente.** Para compilar depende del proyecto anfitrión REVERSE-PC y sus herramientas de build. No hay una APK nueva en este repositorio.
